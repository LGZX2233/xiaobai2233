## 本机复现

使用安装有上版素材和模型的工作机。指定本机 FFmpeg 和可选的 SenseVoice 模型目录。

    python -X utf8 -B mix-v4.py --ffmpeg D:/path/to/ffmpeg.exe --asr

音源为上版的原始音乐与单次音效，按本片转场重新放置。模型版本、输入摘要、逐句语速、声画时间及最终音量见 audio-receipt.json。逐句独立机器转写作为复听辅助，个别音近字与数字会被 ASR 归一化。重合成的音素时长可能轻微变化，脚本会重新生成同步字幕。
