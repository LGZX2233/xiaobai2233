# 事后分析模板

例：`2026-10-13-context-loss-recovery.md`

---

```

严重程度：🔴 Critical / 🟠 High / 🟡 Medium / 🟢 Low
```

## 症状与影响

### 症状
清晰地描述"出了什么问题"。

### 影响范围
- 任务进度：延迟 XX 分钟
- 成本：消耗额外 XX token
- 人工干预：是否需要

### 用户可见性
- ✅ 可见：最终交付出错
- ⚠️ 部分可见：中间异常，最终可恢复
- ❌ 不可见：内部优化失败
