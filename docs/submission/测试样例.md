# 测试样例（正常 / 边界 / 失败）

所有样例都通过内核公开的 JSON-RPC 入口运行，求解器是真实的外部子进程（`tests/p14_science_demo/heat_worker.py`）。证据模式 `test`，执行隔离 `directory_only`（不是操作系统沙盒）。数据是固定种子的合成数据。

下面的输出都是 2026-10-15 在 Linux 沙盒（Python 3.12.14、pytest 9.1.1、Node 22）里实际运行得到的，不是从旧文档抄来的。行号对应撰写时的文件，改动后需要重核。
