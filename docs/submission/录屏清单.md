# 录屏清单（照着做，一步一条命令）

这份清单给"你自己在 Windows 上重录"用。视频里的 AGH 画面，当前主要来自团队在 Linux 沙盒里用自动化浏览器驱动官方 AGH 构建录下的真实操作（记录和截图在 `evidence/agh-run/`，以仓库实际内容为准）。如果你想用自己电脑上的 AGH 重录一遍，按下面做。重录不是必须的；没有重录就不要在视频里说成"在我电脑上操作"。

以下 `<kernel_next>` 指你电脑上的仓库目录。录屏文件统一保存到 `%USERPROFILE%\Downloads\agh-rec\`。每一步都是一条可以直接粘贴到 PowerShell 的命令。

## 开始前先确认（不录）

这四个文件必须已经在仓库里：`tools\install-agh-plugin.ps1`、`tools\start-agh.ps1`、`tools\pk-human-approve.ps1`、`evidence\rehearsal\prompt.md`。其中前三个我们读过源码，没有在 Windows 上执行过。检查命令：

```powershell
cd <kernel_next>; Test-Path tools\install-agh-plugin.ps1, tools\start-agh.ps1, tools\pk-human-approve.ps1, evidence\rehearsal\prompt.md
```

输出四个 `True` 才往下走。有 `False`，先去找负责的同学补，不要自己改脚本。

另外需要：已建好 `.venv`（`start-agh.ps1` 会检查 `.venv\Scripts\python.exe`），Node.js 24 以上，已构建好的 AGH。

## 准备（不录）

1. 新建录屏文件夹：

   ```powershell
   New-Item -ItemType Directory -Force "$env:USERPROFILE\Downloads\agh-rec"
   ```

2. 建 Python 环境（只需一次，要联网）：

   ```powershell
   cd <kernel_next>; py -3.12 -m venv .venv; .\.venv\Scripts\python.exe -m pip install -e .
   ```

3. 安装插件（只需一次）。AGH 会问一次 `Install ...? [y/N]`，这一步必须你亲自输入 `y` 再回车：

   ```powershell
   cd <kernel_next>; powershell -NoProfile -ExecutionPolicy Bypass -File tools\install-agh-plugin.ps1
   ```

   结尾出现"完成：插件已安装、已信任、正在运行"才算成功。

4. 启动 AGH（这个窗口保持打开，不要关）：

   ```powershell
   cd <kernel_next>; powershell -NoProfile -ExecutionPolicy Bypass -File tools\start-agh.ps1
   ```

   如果提示端口被占用，按它给出的 `Stop-Process -Id ...` 命令处理，或者换端口：在命令后面加 ` -Port 5187`，下面的网址对应改。

5. 用浏览器的无痕 / InPrivate 窗口打开 `http://127.0.0.1:5186`，按 `Ctrl+0` 把缩放设为 100%。不要用装了注入脚本扩展的常规窗口，也要关闭浏览器自动翻译。

6. 设置 → 模型与账号：添加你要用的模型账号（DeepSeek 或 Agnes AI），选好模型，**密钥只在这里粘贴**。确认后关掉设置页。录屏时不要再打开它，避免密钥入镜。选了哪个模型，就在视频字幕里写那个模型的 id。

7. 先在 AGH 里新建一个会话，随便发一句"说 ok"，等回复。我们在沙盒里发现：Project Kernel 面板要等插件后端随第一个会话启动后才会出现，之后刷新页面才能看到。然后刷新页面。

8. 用记事本打开 `<kernel_next>\evidence\rehearsal\prompt.md`，全选复制，备用。

9. 再开一个 PowerShell 窗口，`cd <kernel_next>`，放在屏幕一侧，审批时用。字体调大一些（右键标题栏 → 属性）。把提示符缩短，别让个人用户名入镜。

## 开始录制

10. 按 `Win+Alt+R` 开始录屏（Xbox Game Bar；第一次用可能要按 `Win+G` 允许）。也可以用 OBS，输出目录设为 `agh-rec`。Game Bar 默认保存到 `视频\捕获`，录完后把文件移到 `agh-rec`。

## 录制中：AGH 段

11. 在 AGH 新建会话（模型选择器里的模型名要在画面里），粘贴第 8 步复制的提示词，发送。
12. 等模型依次调用工具。每次调用出现后，点开返回结果停 2 秒，让画面看清 `unknown`、`passed: false`、`passed: true`。模型的顺序可能和脚本不同，不用重来，如实录。
12a. 模型要调用 `pk_request_delivery` 时，AGH 自己会先弹出一个工具权限确认框（按钮大意是 Allow once / Allow all / Reject；沙盒里观察到约 60 秒不处理就会超时，超时后模型会如实报告"请求超时、没有执行"，见 `evidence/agh-run/` 的探索截图）。这是 **AGH 的工具权限确认，不是内核里的人工审批**，两者不同。录制时请你在 60 秒内点 `Allow once`（不要点 Allow all，以免后面的调用被静默放行）。点过之后，内核才会生成 pending 审批。
13. 模型说"需要人工批准"后，切到第 9 步的 PowerShell 窗口，粘贴：

    ```powershell
    powershell -NoProfile -ExecutionPolicy Bypass -File tools\pk-human-approve.ps1
    ```

    看清屏幕上列出的快照摘要，**亲手**输入前 8 位，回车。屏幕应显示"已批准"。这一步必须在真正的 PowerShell 窗口里做，不能重定向，否则程序检测不到终端会拒绝，这是有意的。

14. 回到 AGH，输入：`已批准，请执行交付`，发送。等模型调用 `pk_apply_delivery`，看到 `applied: true`。
15. 打开 Project Kernel 面板，依次点：设计 → 执行 → 审批 → 结构 → 事件。每页停 3–5 秒，鼠标指一下底栏的"读取水位"。面板的导航名称以界面实际显示为准（总览、设计、工作区、结构、需求、执行、审批、环境、版本、事件、错误、文档、Skill、知识）。
16. 按 `Win+Alt+R` 停止录制。

## 另录一段：测试（可单独录）

17. 在 PowerShell 粘贴（需已按上面第 2 步建好 `.venv`，且安装了测试依赖）：

    ```powershell
    cd <kernel_next>; .\.venv\Scripts\python.exe -m pip install -e ".[test]"; .\.venv\Scripts\python.exe -m pytest -q tests
    ```

    沙盒里实测是 `627 passed`（约 80–90 秒）。以你屏幕上的数字为准，等结果出来停 2 秒再停止录制。如果数字不是 627，视频旁白里的数字也要改成实际的。

## 录完

18. 把录屏文件改名为 `agh-run.mp4`、`tests.mp4`，放进 `agh-rec`。
19. 对每次工具调用的返回截图（或在 AGH 里导出会话，如果有这个功能），一起放进 `agh-rec`，交给整理证据的同学放入 `evidence/agh-run/`。
20. 出问题（模型没按顺序、工具报错、模型没换策略）也不要删录像，原样保留，告诉整理的同学，按实际情况写进 [运行证据](运行证据.md)。
21. 记下你实际用的模型名和模型 id，写进 [提交材料](提交材料.md) 的模型表。DeepSeek 的版本标签"V4.1 Flash"在 API 里没有确认，写 API 报告的 id，标签标"待队长确认"。

## 常见问题

- 面板没出现：先在 AGH 里发过一条消息（第 7 步），再刷新页面。
- 模型说"我没有这个工具"：到 AGH 的插件状态里确认插件是 `actual=running`、`trusted=true`；重跑第 3 步。
- `pk-human-approve.ps1` 说找不到运行记录：说明模型还没调用过任何 `pk_` 工具。先让模型调用一次，再运行。
- 插件启动 Python 内核失败，提示运行目录必须在系统临时目录下：不要设置 `PK_ROOT`，让插件用默认值。
