# 演示视频脚本（目标 3:55，允许 3:30–4:30；赛方要求 3–5 分钟）

画面以 AGH 内的真实操作为主。来源标记：【AGH】在 AGH 里的真实操作录屏；【终端】录屏中可见的 PowerShell 窗口；【面板】AGH 里的 Project Kernel 面板（没有 AGH 内画面时才退回 `docs/assets/` 的独立渲染图，并在画面角落标"独立渲染，非 AGH 内截图"）；【落地页】直接录 `docs/index.html`。

旁白语速约每秒 4–5 字。数字以仓库测试为准，不要即兴改。

## 先读：模型名怎么说

旁白里出现 `{{模型}}` 的地方，按**录屏里 AGH 实际选中的模型**填，画面右下角同时打字幕显示模型 id。不要凭印象说。

| 实际录到的 | 旁白说 | 字幕 |
| --- | --- | --- |
| DeepSeek（AGH 默认模型，用户选定） | "DeepSeek 模型" | DeepSeek API `/models` 报告的 id（`deepseek-flash` 或 `deepseek-v4-pro`，以录屏为准）。"DeepSeek V4.1 Flash"这个版本标签 API 未确认，待队长确认前不要读出 |
| Agnes 3.0 Flash | "Agnes 3.0 Flash" | `agnes-3.0-flash`，provider `agnes-ai` |
| 两个都录了 | 分别说明各自那一段 | 每段各自字幕 |

比赛文字要求核心任务里有 Agnes 模型。只有 `evidence/agh-run/**` 里确实出现 Agnes 的会话记录时，才能说"Agnes 参与了 AGH 运行"；没有就不说，旁白只说实际用的模型。Agnes 3.0 Flash 已通过 API 单独验证过能返回工具调用，这一点可以在"验证"段说成"另行验证"，不能说成 AGH 运行的一部分。

## 录制注意

- AGH 段落（0:55–3:20）一次连续录完，剪辑时可加速等待部分，但不剪掉任何一次工具调用。
- 模型调用顺序与表中不同（例如先跑 s1），按实际顺序配旁白，不要为了贴脚本重录。模型选了别的策略、或没有换策略，如实说。
- 如果 `pk_apply_delivery` 或 `tools\pk-human-approve.ps1` 在录制时不可用，2:50–3:20 改为：展示"审批"视图里的 pending，旁白说"人工批准入口在测试里验证过（test_heat_inversion_flow.py 和 test_human_approve_cli.py），本次录制没有演示"。不得假装批准成功。
- 画面里不要出现 API 密钥、设置页的密钥输入框、含个人用户名的路径（终端先 `cd` 到仓库，提示符调短）。
- 面板的 node 测试里 `panel.test.mjs` 在界面改版期间曾有失败，视频里不展示 node 测试，除非重跑全绿。
- 画面中的 AGH 如果是在 Linux 沙盒里的自动化浏览器驱动，字幕要写明，不要说成"用户在自己电脑上操作"。
- 视频只放链接，评委不应需要登录：上传到公开可看的平台，主链接加一个备用链接。
