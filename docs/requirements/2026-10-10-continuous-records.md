## 执行范围

“随时更新”在本轮指 agent 工作流维护：目标或技术决定改变时、形成可复用错误解释时、用户纠正学习状态时，以及任务结束时更新相应资料。未经过此项目工作流的文件改动不会自动刷新资料；未来若接入宿主事件，应单独定义生成来源、权限、失败处理和接受条件。

记录是可微调、模型可阅读的 Markdown，用户可以直接修改；本轮不把记录作为模型训练数据导出，不接通可选知识评分或语料导出。可选 library API 的原有评分与新用户学习记录分属不同用途，不把旧分数转成用户评价。
